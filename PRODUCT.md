# Product

## Purpose

Yankee Institute is a nonprofit think tank. The project redesigns its existing WordPress site so visitors can find policy work, understand current priorities and reach relevant calls to action. Initial problem statements identify difficult navigation, buried asks, dated presentation and a site that feels inactive.

## Working audiences

Policy readers, Connecticut residents, journalists, policymakers and prospective supporters are provisional audience groups. Validate their relative priority with the client. Editors need reusable templates they can maintain in WordPress.

## Scope direction

- Information architecture, navigation and CTA hierarchy.
- Visual redesign and responsive content templates.
- Elementor implementation replacing Themify presentation.
- Content migration planning, search and retained custom functionality.
- Performance, measurement, SEO, AEO and practical accessibility improvements.
- Launch preparation and editorial handover.

Exact template counts, content retirement, integration changes and acceptance measures remain to be agreed. Existing proposal and agreement evidence is indexed privately in memory/sources.md.

## Success criteria to define

Agree visitor journeys, priority conversions, editorial workflows, migration coverage and measurable technical acceptance before build. Do not invent traffic or conversion targets. No new application stack or CMS replacement is proposed.
