# Design brief

Status: initial brief, October 1, 2026. No visual direction approved.

## Direction

Create a clear, contemporary and active editorial website grounded in Yankee Institute's identity. Make policy topics, timely work and priority calls to action easy to discover. Use Empower Mississippi as a reference for redesigning an existing WordPress site; do not import its visual identity.

## Discovery before concepts

Inventory existing brand assets, fonts, color roles, imagery, navigation, page types and key journeys. Confirm primary audiences and CTA priorities. Define a retain/rebuild/retire matrix across pages, templates and custom integrations. Distinguish facts from design hypotheses.

## Implementation constraints

Plan reusable Elementor templates and editor-friendly content patterns. Existing Themify pages and some articles require migration assessment. Preserve needed events, forms, donations, contracts data, charts and calculators. Keep URLs or document approved redirects. Do not assume a plugin can be removed merely because it overlaps another plugin.

## Review and acceptance

Present responsive concepts for approval before WordPress implementation. Use actual supplied content or clearly labeled placeholders. Test typography, contrast, keyboard use, focus, reduced motion and layout boundaries on phone, tablet and desktop. Target WCAG AA practices without claiming certification. Establish comparable performance baselines and template-level budgets during discovery.

Design approval, staging acceptance and production launch are separate checkpoints. Record feedback and superseded directions in memory/decisions.md.
